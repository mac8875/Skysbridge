# Skysbridge — Work Plan
Date: 16 September 2026
Branch: `work/site-polish-2026-09-16`
Status: Staging only — do not merge or deploy to production until reviewed.

## Goal
Refine Skysbridge into an even quieter, more elegant and professional memorial experience without changing its identity or core functionality.

## 1. Quieter hero copy
Shorten the first-screen copy so the emotional message comes before operational details.

### English
**Headline stays:** Every child deserves to be remembered.

**Proposed intro:**
Skysbridge is a quiet place to remember a child with love and dignity. Create a star, preserve their name and story, and choose what you wish to share.

Move photo/privacy mechanics out of the main emotional paragraph and keep them in the trust/privacy/how-it-works areas.

### German
**Headline stays:** Jedes Kind verdient es, erinnert zu werden.

**Proposed intro:**
Skysbridge ist ein stiller Ort, an dem ein Kind mit Liebe und Würde in Erinnerung bleiben darf. Schaffe einen Stern, bewahre seinen Namen und seine Geschichte und entscheide selbst, was du teilen möchtest.

### Spanish
**Proposed intro:**
Skysbridge es un lugar sereno para recordar a un hijo con amor y dignidad. Crea una estrella, conserva su nombre y su historia, y decide qué deseas compartir.

## 2. Reduce top-navigation cognitive load
Remove the SEO-oriented child-loss information page from the primary desktop navigation while keeping it accessible from contextual links, footer/SEO pages and hreflang/canonical structure.

Target primary navigation:
- A Sky Full of Stars / Ein Himmel voller Sterne / Un cielo lleno de estrellas
- Sky's Story / Skys Geschichte / La historia de Sky
- How It Works / So funktioniert es / Cómo funciona
- Community / Gemeinschaft / Comunidad
- Professional Help / Professionelle Hilfe / Ayuda profesional
- Honor a child / Ein Kind ehren / Honrar a un hijo

Do not remove the child-loss memorial pages themselves.

## 3. Replace emoji locks with a site-native lock treatment
Replace the visible 🔒 emoji in guest community cards with a small CSS-drawn gold line lock.

Requirements:
- no emoji
- visually quiet
- same dark-blue/gold visual language as the rest of the site
- accessible text remains visible (e.g. “Approval required”)
- works on mobile and desktop

## 4. Security-header hardening
Add conservative browser security headers that should not interfere with Supabase auth or current functionality:

- `X-Content-Type-Options: nosniff`
- `Referrer-Policy: strict-origin-when-cross-origin`
- `Permissions-Policy: camera=(), microphone=(), geolocation=()`
- `X-Frame-Options: DENY`

Do not add a restrictive CSP until it has been tested against Supabase, Google Fonts and all inline/runtime scripts.

## 5. Automated smoke-test starter
Add a lightweight smoke-test script for production/staging URLs.

Initial checks:
- EN, DE, ES home pages return 200
- Sky's Story pages return 200
- How It Works pages return 200
- Privacy pages return 200
- Professional Help pages return 200
- expected home-page headline exists in each language
- `A Sky Full of Stars` section exists
- no obvious server error page returned

Later phase: browser-based interaction tests for menu, auth modal, Honor a Child flow, member-only photos, memorial opening and community access.

## 6. Review checklist before any merge
- Desktop visual review
- Android/mobile visual review
- EN/DE/ES copy review
- Sign-in and sign-out check
- Honor a Child modal check
- Guest cannot see memorial photos
- Signed-in member can see approved photos
- Existing memorial stars still load
- Search/sort still work
- Community guest/member states still work
- Professional Help links still work
- No Netlify build warnings/errors introduced

## Production rule
No automatic merge to `main` and no production deploy from this work package. Review the staged changes first.
