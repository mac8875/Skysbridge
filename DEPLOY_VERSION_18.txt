VERSION 18 DEPLOYMENT

1. Upload all files in this folder to the root of the GitHub repository.
2. Run V18_RUN_THIS_IN_SUPABASE.sql in Supabase SQL Editor.
3. In Netlify > Site configuration > Environment variables add:
   ROOM_MESSAGE_FORWARD_TO=together@skysbridge.org
   RESEND_API_KEY=your Resend API key
   MAIL_FROM=Sky's Bridge <notifications@skysbridge.org>
4. Trigger a Netlify deploy.
5. Log out and back in, then test a message in a forwarding-enabled room.

Privacy: only enable forwarding in rooms whose members are clearly informed. Forwarding to a clinician should follow consent and applicable privacy rules.
